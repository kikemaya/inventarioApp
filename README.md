# InventarioApp
InventarioApp is a simple inventory management application written in .NET. It provides basic CRUD operations.

## Project structure
- `Program.cs` - application entry point
- `InventarioApp.csproj` - project file
- `src/` - source files (if present)
- `bin/`, `obj/` - build artifacts

## Troubleshooting / Common Errors
- If `dotnet` is not found, ensure the .NET SDK is installed and present in PATH.
- Build failures: run `dotnet build` and inspect the errors displayed. Share error output when filing issues.
